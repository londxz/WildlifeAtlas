3) Уточнял что значит требование "возможность просматривать все доступные фото наблюдения во встроенной в экран галерее"

Но случай с местностью другой - приватные наблюдения это ожидаемое состояние
7) Уточнял по требованию "Локальные закладки: раздел с избранными наблюдениями" - куда лучше на главном экране засунуть кнопку. В навбар нет, решил в таббар, потому что это переход на другой экран

# Дополнение от AI

## Отклонённые или изменённые предложения AI

- **Использовать iNaturalist API v1.** Отклонено, потому что в задании дана ссылка и ожидается работа с API v2.
- **Сделать `URLSessionAPIClient` actor.** Отклонено: у клиента нет изменяемого состояния, требующего actor isolation.
- **Пометить `AppDependencies` и связанные типы целиком `MainActor`.** Изоляция сужена до UI-состояния и SwiftData.
- **Передавать краткую модель ленты как готовые детали.** Вместо этого детали загружаются отдельным запросом, а полная локальная модель передаётся только из Favorites.
- **Повторно загружать избранные наблюдения из сети.** Отклонено в пользу хранения полного snapshot в SwiftData.
- **Полностью скрывать секцию приватной локации.** Изменено: защищённые данные не показываются, но пользователь видит объяснение `Location obscured`.
- **Хранить одновременно числовой `id` и UUID наблюдения.** Оставлен только UUID как единый источник идентичности.
- **Хранить все файлы Observations в одной папке.** Feature разделена на логические подпапки.
- **Использовать системный `.searchable` с кнопкой Cancel.** Заменено собственным полем поиска, соответствующим макету.
- **Показывать только spinner при первоначальной загрузке.** Заменено skeleton-состоянием с shimmer.
- **Сохранять страницы ленты между запусками.** Отклонено: на диск сохраняются только пользовательские настройки, последние таксоны и избранное.
- **Добавить лишние слои архитектуры.** Coordinator, use-case и отдельные data-source типы не добавлялись, потому что не давали новой ответственности в рамках задания.
